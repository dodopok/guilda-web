# Guilda Web

Plano de um web app para escalas, confirmações e roteiros de culto de uma igreja anglicana. Interface em Vue e Nuxt 4. Ainda não há aplicação implementada.

## Etapas

| Etapa | Resultado |
| --- | --- |
| [0. Descoberta](docs/etapas/00-descoberta.md) | Fontes analisadas e regras validadas |
| [1. Base](docs/etapas/01-base.md) | Pessoas, funções, cultos e acesso |
| [2. Escalas](docs/etapas/02-escalas.md) | Coleta de indisponibilidades, editor e alertas de distribuição |
| [3. Lembretes por WhatsApp](docs/etapas/03-lembretes.md) | Envio semanal automático; requisito do primeiro lançamento |
| [4. Confirmações](docs/etapas/04-confirmacoes.md) | Respostas e trocas no app e, depois, no WhatsApp |
| [5. Liturgia](docs/etapas/05-liturgia.md) | Roteiro revisável e publicado |
| [6. Estêvão](docs/etapas/06-estevao.md) | Sugestões de leituras, coleta e calendário |

O primeiro lançamento reúne as etapas 1 a 6: coleta de indisponibilidades, escalas, lembretes automáticos, confirmações e trocas no app, roteiro publicável e integração litúrgica com o Estêvão.
